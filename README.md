# GLSLextension
My own custom vscode-extension for glsl shaders.

Syntax highlighting grammar adapted from **GeForceLegend/vscode-glsl** \
Original project: https://github.com/GeForceLegend/vscode-glsl \
Modified for **GLSLextension**.

### Features:

- Syntax Highlighting
- Auto-Completion
- Hover Information
- Signature Help
